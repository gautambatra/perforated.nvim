INTRODUCTION                                                *perforated-intro*

perforated.nvim integrates Perforce (Helix Core) into Neovim. Every p4 call is
asynchronous; the plugin stays dormant outside Perforce workspaces (a P4CONFIG
lookup per directory) and loads its modules only when a workspace file is
opened or a :P4 command runs. All state is per Neovim session. No setup() call
is required: configure with `vim.g.perforated = { ... }` or
`require("perforated").setup({ ... })`.

Check your setup with `:checkhealth perforated`. `:P4 log` lists every p4
command the plugin ran, and `:P4 debug on` writes a diagnostic log.

COMMANDS                                                 *perforated-commands*

Everything is a subcommand of `:P4` (completion lists them). Each also has a
flat alias, `:P4<sub>` (e.g. `:P4edit`), defined the first time you use it. A
bang goes on the subcommand: `:P4 revert!`.

:P4 add                                                              *:P4-add*
    Open files for add: :P4 add [-c CL] [file…]

:P4 annotate                                                    *:P4-annotate*
    Annotate the current file (or a depot revision): :P4 annotate
    [//depot/path#rev]

:P4 blame                                                          *:P4-blame*
    Current-line blame (virtual text): :P4 blame [on|off] (no args: toggle)

:P4 cancel                                                        *:P4-cancel*
    Stop every running p4 job (sync, submit)

:P4 change                                                        *:P4-change*
    Edit a changelist description: :P4 change[!] [N|new] (! = full spec; no N
    = current file's CL); :P4 change -d N deletes a pending CL

:P4 changes                                                      *:P4-changes*
    Submitted changelists: :P4 changes [-u user] [-m N] [path] (default: this
    client)

:P4 debug                                                          *:P4-debug*
    Debug log: :P4 debug [on [level]|off|open|clear|snapshot|timings] (no
    args: status)

:P4 delete                                                        *:P4-delete*
    Open files for delete (with a confirmation): :P4 delete [file…]

:P4 describe                                                    *:P4-describe*
    Describe a changelist: :P4 describe [N|default] (no N = the current file's
    CL)

:P4 diff                                                            *:P4-diff*
    Diff the current file: :P4 diff[!] [#rev|@CL|@=shelf|prev] (! = $P4DIFF);
    -a = all opened

:P4 dismiss                                                      *:P4-dismiss*
    Dismiss visible notifications

:P4 edit                                                            *:P4-edit*
    Open files for edit: :P4 edit [-c CL] [file…] (default: sticky CL or
    default)

:P4 filelog                                                      *:P4-filelog*
    File history: :P4 filelog [file|//depot/path|dir] (default: current file;
    a directory lists its changelists)

:P4 history                                                      *:P4-history*
    Alias of :P4 filelog

:P4 hunks                                                          *:P4-hunks*
    Hunks of all opened files (quickfix), or of this file: :P4 hunks %
    (location list)

:P4 info                                                            *:P4-info*
    Show workspace, connection and server information

:P4 integrate                                                  *:P4-integrate*
    Cherry-pick a submitted changelist: :P4 integrate [CL] (no CL: pick from a
    source path)

:P4 jobs                                                            *:P4-jobs*
    Running p4 jobs (sync, submit), live; x in the list stops one

:P4 log                                                              *:P4-log*
    Show the log of p4 commands run by the plugin (with timings)

:P4 login                                                          *:P4-login*
    Log in to the Perforce server (password prompt)

:P4 lookup                                                        *:P4-lookup*
    Go to a changelist (number), a file or directory history (path) or a user:
    :P4 lookup [what]

:P4 move                                                            *:P4-move*
    Move/rename the current file: :P4 move {new path}

:P4 notifications                                          *:P4-notifications*
    Show recent notifications (stale files, …)

:P4 opened                                                        *:P4-opened*
    Opened files, grouped by changelist, in the quickfix list

:P4 p4vc                                                            *:P4-p4vc*
    P4V tools: :P4 p4vc {revgraph|timelapse|streamgraph} [file] (default: the
    current file)

:P4 pick                                                            *:P4-pick*
    Picker: :P4 pick {pending|opened|submitted|users}

:P4 refresh                                                      *:P4-refresh*
    Refresh cached state (! also forgets workspace detection and settings)

:P4 reopen                                                        *:P4-reopen*
    Move opened files to another changelist: :P4 reopen [-c CL] [file…] (no
    -c: pick one)

:P4 resolve                                                      *:P4-resolve*
    Resolve: :P4 resolve [file…] (-am first, then $P4MERGE for conflicts; no
    args: all files)

:P4 revert                                                        *:P4-revert*
    Revert files: :P4 revert[!] [-a] [file…] (! = no confirmation, -a = only
    unchanged)

:P4 shelve                                                        *:P4-shelve*
    Shelve: :P4 shelve [-c CL] [file…] (default: the current file's CL, all
    its files; -d deletes the shelf)

:P4 status                                                        *:P4-status*
    Stale and unresolved opened files in the quickfix list

:P4 submit                                                        *:P4-submit*
    Submit a changelist (with a confirmation): :P4 submit [CL|default]
    (default: the current file's CL)

:P4 sync                                                            *:P4-sync*
    Sync the whole workspace (:P4 sync), or get the latest revision of files
    (:P4 sync %|path …); @CL / #head for a revision

:P4 timelapse                                                  *:P4-timelapse*
    Time-lapse: step through every revision of the current file (or a depot
    path)

:P4 unshelve                                                    *:P4-unshelve*
    Unshelve: :P4 unshelve CL [-c target] [//depot/file…]

:P4 view                                                            *:P4-view*
    Client view: :P4 view [tab|float|split] (also plain :P4)

KEYS IN PLUGIN VIEWS                                         *perforated-keys*

Plugin views have buffer-local keys from one action registry, which also
drives the `.` action menu (right-click too), the `?` help and the key footer.
Change any action's keys with `keys = { <id> = { "x" } }` (or `false` to
remove them); `keys.p4v = false` removes the P4V-style keys (<C-d>, <C-r>,
...). The ids are listed in the `?` help of each view.

EVENTS                                                     *perforated-events*

`User` autocmds you can hook (the event data is in `ev.data`):

  PerforatedStatus        workspace / buffer state changed (statuslines)
  PerforatedChanged       files were opened, reverted, submitted, ... { ws }
  PerforatedWorkspaceActivated   a workspace became active { ws }
  PerforatedWorkspaceIdle        a workspace went idle (no buffers left) { ws }
  PerforatedDiffOpen      a diff tab opened { tab, wins, bufs, spec, path }
  PerforatedDiffClose     it closed (same data)
